In short

yt-pubx is a command-line program that publishes videos to YouTube for you. It is meant for people who publish often, on one or several channels, and don't want to fill in the title, description, tags and thumbnail by hand every time. From a short text or the video's subtitles, the Codex CLI writes the texts and creates the thumbnail art, and yt-pubx uploads everything through the official YouTube API. To use it, you need Python, a logged-in Codex CLI and a free Google Cloud project with the YouTube Data API enabled.

What it is

From file to published video, without opening Studio

A single Python file. The configuration and tokens stay on your machine.

✍️ Codex writes

A title of up to 90 characters, a description with bullet points and only the links you provided, tags, and the thumbnail phrase and scene. All through your Codex subscription, with no model API key.

🖼️ Thumbnail with your brand

The art comes from the Codex image generator; yt-pubx darkens the text side and applies the phrase, the brand label and the colors defined for each channel.

📺 As many channels as you want

Each channel is one block in config.json and one yt-pubx auth. Pick it with --canal; without it, the video goes to the default channel.

How it works

Five steps, one command line

With --dry-run it stops before uploading and shows everything; with --plano it publishes exactly what you reviewed.

Video (file or link)→ Codex: title, description, tags→ Codex image_gen: art→ Thumbnail with the channel brand→ Upload + thumbnail + subtitles

Input

Local file, direct .mp4 link or a YouTube, TikTok or Instagram link (downloaded with yt-dlp, or with the command you configure).

Upload

Resumable upload in 16 MB chunks with retries. Public, unlisted, private or scheduled with --agendar.

Record

Each upload creates a folder with plano.json, the thumbnail and the art, plus a line in historico.jsonl.

Prerequisites

What needs to be on your machine

Linux, macOS or Windows (WSL). Nothing lives on a third-party server.

Python + ffprobe

Python 3.10 or newer, with requests and Pillow; ffprobe comes with ffmpeg.

pip install requests pillow
ffprobe -version

Codex CLI

Logged in to your ChatGPT account. It is what writes the texts and draws the art.

npm i -g @openai/codex
codex login

Google Cloud

A free project with the YouTube Data API v3 enabled and an OAuth client ID of type "Desktop app" (step 2 of the guide).

# optional, for links
pip install yt-dlp
User guide · step by step

From zero to your first published video

Steps 2 to 4 are done once per channel. After that, publishing is just step 5.

1

Install and create the configuration

Clone the repository, put the command on your PATH and generate the sample file at ~/.config/yt-pubx/config.json.

git clone https://github.com/inematds/yt-pubx.git
cd yt-pubx && ln -s "$PWD/yt-pubx" ~/.local/bin/yt-pubx
yt-pubx init
2

Enable YouTube in Google Cloud

At console.cloud.google.com: create a project; under APIs & Services → Library enable the YouTube Data API v3; on the OAuth consent screen choose "External" and add the email of the account that owns the channel as a test user; under Credentials → Create credentials → OAuth client ID choose Desktop app and download the JSON.

# keep the JSON outside any repository
mv ~/Downloads/client_secret_*.json ~/.config/yt-pubx/
3

Describe the channel in the config

Name, one sentence about the channel (it sets the tone of the texts), the line that closes every description and the thumbnail identity.

"principal": {
  "nome": "My Channel",
  "sobre": "Short smartphone photography tutorials.",
  "assinatura": "Subscribe: https://www.youtube.com/@meucanal",
  "idioma": "pt", "categoria": "27", "privacy": "public",
  "thumb": { "marca": "MY CHANNEL", "cor_marca": "#f0e805", "cor_destaque": "#f91f06" }
}
4

Authorize the channel (once)

It opens the browser; sign in with the account that owns the channel and accept. The token is stored in ~/.config/yt-pubx/tokens/ with permission 600. For another channel, create another block and repeat with its name.

yt-pubx auth principal --client-secret ~/.config/yt-pubx/client_secret_XXXX.json
yt-pubx canais   # * principal  My Channel  ...  ok
5

Review before uploading

--dry-run generates the title, description, tags and thumbnail and shows everything without publishing. Open the thumb.jpg in the folder it points to.

yt-pubx publicar aula.mp4 --legenda aula.srt \
  --contexto "Lesson 3 of course X. Page: https://exemplo.com/curso" --dry-run
# PLANO: ~/.local/share/yt-pubx/trabalhos/20261007-163325-aula-mp4/plano.json
6

Publish what you reviewed

--plano reuses the text and the art without generating them again. You can change just the thumbnail phrase. At the end you get the video link and the Studio link.

yt-pubx publicar aula.mp4 --plano ~/.local/share/yt-pubx/trabalhos/<folder>/plano.json \
  --frase-thumb "From zero to live"
# URL: https://www.youtube.com/watch?v=...
7

Useful variations

Another channel, a link instead of a file, scheduling, or everything by hand without Codex.

yt-pubx publicar https://exemplo.com/video.mp4 --canal segundo --contexto "..."
yt-pubx publicar video.mp4 --contexto "..." --agendar "2026-12-01 18:00"
yt-pubx publicar video.mp4 --title "..." --description "..." --tags "a,b" --thumb capa.jpg
yt-pubx atualizar https://www.youtube.com/watch?v=XXXXXXXXXXX --description-arquivo descricao.txt  # edit a video that is already published
8

Let an agent do it for you

Put this instruction in your agent's CLAUDE.md or AGENTS.md; then just ask "publish this video on channel X".

# Publish a video to YouTube
Gather the context (topic, official links, SRT), run
yt-pubx publicar <video> --contexto "..." --dry-run, open thumb.jpg,
check the title and description and publish with --plano <folder>/plano.json.

⚠️ Google pitfalls

App in Testing mode: access expires in 7 days; publish the app on the consent screen so it doesn't expire. Unaudited project: YouTube may lock videos from new projects as private until the YouTube API Services audit (free). Quota: 10,000 units per day; each upload uses a good part of it. Custom thumbnail: requires a phone-verified channel.
